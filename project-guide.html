01 · Getting started

Build the registered test target

Requirements: CMake 3.16 or newer and a C++17 compiler supported by CMake. On Windows with MSVC, install Visual Studio’s C++ workload. The top-level CMake configuration does not declare automatic third-party downloads.

cmake -S . -B build
cmake --build build --config Release --target xfrontend_tests
ctest --test-dir build -C Release --output-on-failure

The top-level CMake file registers xfrontend_tests as the CTest entry. Focused suites and historical host-validation scripts are separate; a normal CTest run does not mean they all ran.

Evidence boundary: the local N114 v10.63 workspace passed the declared Full Regression inventory (175,976/175,976; 26/26 batches) under Windows/MSVC. The runner did not capture a source commit SHA, and the tested local tree is not yet proven identical to public main. This is not a claim that these commands have been run against the current public source tree.
02 · Current architecture

From source text to native output

X source
  → parse_source
  → CompilationUnit
  → compile_x64_coff_program
  → AMD64 COFF objects + deterministic link plan
  → platform linker

parse_source parses source text. compile_x64_coff_program receives already-parsed CompilationUnit values and emits COFF modules plus a deterministic link plan; the platform linker creates the final PE32+ executable.

The active backend is custom x64 code, not LLVM. AMD64 is the COFF machine designation used by the current Windows x64 path.

Roadmap and current implementation

TargetCurrent evidence
Windows x64Integrated compiler API emits AMD64 COFF objects and a link plan; the platform linker creates PE32+.
Linux x64ELF64 components and scoped Linux-host LLD evidence exist; full source-to-ELF is not established.
X32 / x86-32Roadmap target; not implemented in the current target model/backend. X32 means 32-bit x86, not Linux x32 ABI.
macOSFuture target; Mach-O output and macOS validation are not established.

My plan is to support x86-32 and x86-64 on Windows and Linux, with macOS later. This is a goal, not a claim that all targets work today.

راهنمای فارسی

راهنمای ساخت و وضعیت

پیش‌نیاز: CMake نسخهٔ ۳٫۱۶ یا بالاتر و کامپایلر C++17. برای ساخت با MSVC در Windows، workload زبان C++ در Visual Studio لازم است.

cmake -S . -B build
cmake --build build --config Release --target xfrontend_tests
ctest --test-dir build -C Release --output-on-failure

این فرمان‌ها هدف آزمون ثبت‌شده در CTest را اجرا می‌کنند؛ به معنی اجرای همهٔ suiteها یا workloadهای تاریخی نیست.

وضعیت N114 v10.63: Full Regression روی Workspace محلی کاربر، ۱۷۵٬۹۷۶ از ۱۷۵٬۹۷۶ تست و ۲۶ از ۲۶ Batch را با موفقیت گذراند؛ هر ۹ هدف Build نیز موفق شدند. Runner، SHA مربوط به commit سورس را ثبت نکرده و یکسانی درخت آزموده‌شده با main عمومی اثبات نشده است؛ بنابراین این رکورد اثبات‌کنندهٔ وضعیت فعلی سورس عمومی نیست. جزئیات در رکورد Full Regression آمده است.

خلاصهٔ پلتفرم‌ها

  • Windows x64: مسیر جاری COFF و PE32+.
  • Linux x64: اجزای ELF64 هست؛ مسیر کامل سورس تا ELF اثبات نشده.
  • X32 / x86-32: هدف نقشهٔ راه است، اما هنوز پیاده‌سازی نشده.
  • macOS: هدف آینده؛ Mach-O و اعتبارسنجی آن موجود نیست.
