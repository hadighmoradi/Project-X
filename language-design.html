A language taking shape · Design overview

Simple to write.
Native by design.

Project X aims to combine approachable code, native execution, and compact standalone programs. This page shows the ideas behind the design, the current public compiler evidence, and what is still ahead.

Design goalsCurrent prototypeFuture roadmap
01 · The three goals

What should the language feel like?

These are intended product qualities, not performance claims about the current experimental compiler.

01

Readable code

Common tasks should be clear, direct, and approachable, without unnecessary syntax ceremony.

02

Native execution

Compile to native program output and measure performance against equivalent C/C++ workloads.

03

Compact executables

Link only needed runtime and library pieces; avoid forcing unused infrastructure into every program.

02 · Design inspirations

Good ideas from different languages

These are design influences and comparison points. X is not a copy of any one language, and the references do not mean every related feature has been implemented.

Visual Basic · readability

Keep the language friendly and straightforward for everyday code.

Primary inspiration in the latest architecture brief

Python · high-level APIs

Make common file, process, and everyday library operations easy to express, while keeping X compiled and native.

Comparison reference in earlier syntax notes

C / C++ · native power

Preserve systems-level access and use equivalent C/C++ programs as a meaningful performance reference.

Performance remains a benchmark target, not a measured promise

Rust · explicit safety

Pay attention to clear types, ownership, resource lifetime, and explicit error contracts.

Design comparison reference

Windows Batch / CMD · direct operations

Use clear verbs and simple operations for files, folders, environment, arguments, and processes — not fragile CMD parsing.

Design comparison reference

PureBasic · Delphi / Lazarus · GUI

Learn from simple GUI APIs and integrated visual form-design tools.

GUI and IDE experience references

Earlier syntax comparison notes additionally discuss Python, Rust, Windows Batch/CMD, and PureBasic for specific API and GUI ideas. These references may change as the design is reviewed.
03 · Small output

Compact programs come from engineering choices

We do not attribute small executables to one source language. The design relies on selective linking and avoiding unnecessary runtime overhead.

Native compilation
No required interpreter for each app
→
Modular runtime + static linking
Choose only what the program needs
→
Measure the result
EXE size · startup · runtime overhead
Important: Static linking alone does not guarantee a small executable. Size and speed must be measured on repeatable, equivalent workloads.
04 · Syntax at a glance

Readable blocks, explicit statements

The compact syntax reference documents UTF-8 .src files, braces, semicolons, and the function keyword. Full type and memory rules live in separate design documents.

Function

function Add(a, b) {
    return a + b;
}

Condition

if (ready) {
    PrintLine "Ready";
} else {
    PrintLine "Wait";
}

Form description

Form MainForm {
    Caption = "Hello";
    Button SaveButton {
        Caption = "Save";
        OnClick = HandleSave;
    }
}
The .frm form file is designed as declarative design-time input, paired with .src code. The visual designer and production integration are still work to complete; these examples do not prove that the complete language is currently supported by the public compiler.

۰۴ · نگاه سریع به نحو

بلوک‌های خوانا و دستورهای مشخص

مرجع فشردهٔ نحو، فایل UTF-8 با پسوند .src، آکولاد، سمی‌کالن و کلیدواژهٔ function را مشخص می‌کند.

function Add(a, b) {
    return a + b;
}

if (ready) {
    PrintLine "آماده است";
} else {
    PrintLine "صبر کنید";
}

فایل .frm برای توصیف فرم به‌صورت declarative طراحی شده و با کد .src جفت می‌شود. Designer بصری و اتصال کامل به Runtime هنوز در حال تکمیل‌اند.

۰۷ · مشارکت جامعه

از X چه انتظاری دارید؟

بگویید چه برنامه‌ای می‌خواهید بسازید، چه قابلیت‌هایی برایتان مهم‌ترند و چه چیزی را در زبان‌های دیگر بهتر می‌کردید. پیشنهادها بررسی می‌شوند؛ اما نمی‌توان قول داد همهٔ درخواست‌ها به زبان اضافه شوند.
