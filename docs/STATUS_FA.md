# وضعیت پروژه

Project X یک پروژهٔ آزمایشی برای ساخت زبان کامپایل‌شونده است. مخزن فعلی شامل frontend مبتنی بر C++17 و backend اختصاصی تولید کد Native برای x64 است. خود زبان، Runtime و ابزارهای توسعه همچنان در حال تکمیل‌اند.

## قابلیت‌های پیاده‌سازی‌شده در کامپایلر فعلی

- متن سورس به `CompilationUnit` تبدیل می‌شود.
- frontend برای ساختارهای پیاده‌سازی‌شده، تحلیل معنایی و کنترل جریان انجام می‌دهد.
- مدل کنترل جریان، شاخه‌های دستورها و مسیرهای سطح Expression برای عملگرهای کوتاه‌مدار مانند `&&` و `||` را نمایش می‌دهد.
- مسیر تولید کد Windows x64 ماژول‌های AMD64 COFF و یک link plan قطعی تولید می‌کند. linker پلتفرم فایل اجرایی نهایی PE32+ را می‌سازد.
- مخزن مجموعه‌های Regression برای frontend، تحلیل کنترل جریان، تولید کد Native و ساخت Object دارد.

## پیشرفت اخیر

کار اخیر N114 مسیرهای Expressionهای کوتاه‌مدار را در مدل کنترل جریان صریح‌تر کرده است. هویت edgeهای Expression حفظ می‌شود، مسیرهای قابل‌اجرا در تحلیل از مسیرهای لازم برای تولید کد ماشین تفکیک می‌شوند و محل شاخه‌های Native هنگام چیدمان کد دنبال می‌شود. هدف، قابل‌بررسی‌تر و پایدارترشدن تحلیل کنترل جریان و مدیریت مقصد شاخه‌هاست.

توضیح فنی در [milestone کنترل جریان Expression در N114](milestones/N114_EXPRESSION_CONTROL_FLOW_2026-11-27_FA.md) آمده است.

## بخش‌های در حال توسعه

- مشخصات کامل و پایدار زبان و مجموعهٔ کامل قابلیت‌های آن.
- Runtime ماژولار و کتابخانهٔ استاندارد.
- پشتیبانی یکپارچهٔ IDE و طراح بصری فرم‌های Windows.
- مسیر کامل کامپایل سورس به ELF بومی برای Linux x64.
- تولید کد x86-32 و خروجی بومی macOS.

## جهت‌گیری پلتفرم‌ها

| هدف | وضعیت فعلی |
|---|---|
| Windows x64 | مسیر یکپارچهٔ کامپایلر ماژول‌های AMD64 COFF و link plan برای ساخت PE32+ تولید می‌کند. |
| Linux x64 | اجزای ELF64 وجود دارند؛ مسیر کامل کامپایل سورس تا ELF همچنان در حال توسعه است. |
| X32 / x86-32 | در نقشهٔ راه است؛ در backend فعلی پیاده‌سازی نشده است. |
| macOS | هدف آینده است؛ خروجی Mach-O پیاده‌سازی نشده است. |

این پروژه هنوز به‌عنوان یک زبان کامل یا دارای گواهی آمادگی برای استفادهٔ تولیدی معرفی نمی‌شود. قابلیت‌هایی که به‌عنوان هدف یا کار در حال توسعه توصیف می‌شوند، نباید قابلیت آمادهٔ کامپایلر تلقی شوند.
