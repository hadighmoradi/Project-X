# Project X licensing policy

This page records the component policy documented in the project's decision register:

| Component | Policy |
|---|---|
| Compiler, IDE, interpreter, core development tools | GPL-3.0-or-later |
| Runtime library | LGPL-3.0-or-later with the X Runtime Linking Exception |
| Project documentation | CC BY-SA 4.0 |
| Standalone examples | MIT only when the individual file declares that license |

The project owner has confirmed that they own the project materials and have authority to prepare them for publication. This snapshot includes the full GPLv3 license text in [LICENSE](../LICENSE) for source code and the CC BY-SA 4.0 legal code in [LICENSES/CC-BY-SA-4.0.txt](../LICENSES/CC-BY-SA-4.0.txt) for project documentation. Project scope is summarized in [COPYRIGHT.md](../COPYRIGHT.md).

This source snapshot does not include a runtime implementation, so the runtime license and X Runtime Linking Exception do not apply to a runtime component in this package. Before a runtime is distributed, its final exception text and static/dynamic linking terms must be added alongside it. A third-party notice audit and contributor/CLA process are still open. This summary does not replace per-file license notices where a file declares different terms.
