# تاریخچهٔ توسعه

این صفحه مراحل اصلی توسعهٔ Project X را ثبت می‌کند و بر تغییرات frontend زبان، معماری کامپایلر و تولید کد Native تمرکز دارد.

| مرحله | پیشرفت |
|---|---|
| پایه‌های زبان | ایجاد frontend سورس، مدل parsing، ساختار نحو و تحلیل معنایی اولیه. |
| ساختار برنامه و معناشناسی | گسترش تابع‌ها، متغیرها، نوع‌ها، ownership و تحلیل کنترل جریان. |
| قالب‌های Object و Executable | ایجاد ساختار فایل‌های Object، import و export، link planning و پشتیبانی PE32+ ویندوز. |
| تولید کد Native برای x64 | توسعهٔ مسیر اختصاصی code generation برای AMD64 و اتصال آن به فرایند تولید Object و لینک Windows. |
| تخصیص Register و کنترل جریان | گسترش تحلیل Register، طراحی Stack Frame، گراف کنترل جریان و تولید کد چندبخشی. |
| کنترل جریان Expression | افزودن مدل صریح کنترل جریان برای عبارت‌های منطقی کوتاه‌مدار، هویت پایدار edgeهای Expression و دنبال‌کردن محل شاخه‌های Native. |

## مسیر فعلی

کامپایلر با هدف ساخت زبانی خوانا و Native توسعه پیدا می‌کند؛ زبانی که هم برای برنامه‌های روزمره مناسب باشد و هم در آینده امکان کارهای سطح پایین سیستمی را فراهم کند. تمرکز فنی فعلی بر کامل‌کردن frontend، صحت تحلیل کنترل جریان، تخصیص Register و تولید کد Native برای x64 است.

Runtime، کتابخانهٔ استاندارد، مشخصات کامل زبان، IDE یکپارچه، طراح بصری فرم‌ها و هدف‌های Native خارج از Windows همچنان در حال توسعه‌اند. قابلیت‌های برنامه‌ریزی‌شده به‌عنوان قابلیت پیاده‌سازی‌شده معرفی نمی‌شوند.

برای آشنایی با وضعیت فنی، [وضعیت پروژه](STATUS_FA.md)، [طراحی زبان](LANGUAGE_DESIGN_FA.md) و [معماری](ARCHITECTURE.md) را ببینید.
